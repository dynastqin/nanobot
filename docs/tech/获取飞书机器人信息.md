## 1. 本地配置（config.json）

直接读取实例配置文件：

```bash
cat $NANOBOT_HOME/config.json | jq '.channels.feishu'
```

可获取：`appId`、`appSecret`、`domain`、`groupPolicy` 等通道配置。

---

## 2. bot/v3/info API（无需额外权限）

**最通用的接口**，只需 `tenant_access_token` 即可调用，可获取：应用名称、bot_open_id、头像 URL、激活状态。

```bash
# 步骤1: 获取 tenant_access_token
TOKEN=$(curl -s -X POST 'https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal' \
  -H 'Content-Type: application/json' \
  -d '{"app_id":"cli_a921034c6da15ced","app_secret":"<appSecret>"}' | jq -r '.tenant_access_token')

# 步骤2: 获取机器人信息
curl -s "https://open.feishu.cn/open-apis/bot/v3/info" \
  -H "Authorization: Bearer $TOKEN" | jq .
```

返回示例：

```json
{
  "bot": {
    "activate_status": 2,
    "app_name": "dy-bot",
    "avatar_url": "https://s1-imfile.feishucdn.com/static-resource/v1/v3_00vi_76eb1e12-aa69-4330-aa01-957b1136a50g",
    "ip_white_list": [],
    "open_id": "ou_52fb9ed40e96bf504cdf2604a3eaf562"
  }
}
```
